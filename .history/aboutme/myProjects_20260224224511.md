## Project 1: Snake Game With A Bomb

### Description

This was my final project for my programming 1 course. It's a console snake game built in Visual Studio using C# with a little twist where a bomb will spawn and end the game if touched.

---

**The Game Includes**:
- Keyboard movements using "WASD"
- A score system
- A game-over condition
- Collision
- The unique twist with the orb

---

### Technology Used

- Random Number Generator
- Loop Logic

## Project 2: Humidifier Control System

### Description

This project simulates the control of a home's central humidifier system. It monitors humidity and temperature values and activates the humidifier only when specific requirements are met.

The program follows testing using parallel arrays to simulate mulitple test cases.

**The Conditions**:
- Current humidity is below a defined threshold
- Temperature is above a set threshold
- Temperature remains bwlow 60°C
  
---

### Technology Used

- C#
- Console Application
- Boolean Logic
- Parallel Arrays
- Constants
